# Pack staging area

`overrides/` contains the curated text configuration updates for the next revision.

The original export also had seven additional JAR files under `overrides/mods/`; the public repository does not redistribute those binary files. Install the original modpack first. No test world, Xaero map cache, player/session cache, launcher preferences or logs are included here.

This is a quest/configuration overlay, not a complete standalone `.mrpack` archive.
